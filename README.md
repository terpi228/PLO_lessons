# Проект: Категории и товары

Данный проект представляет собой простую реализацию классов `Category` и `Product` для работы с категориями товаров, а также утилиту для загрузки данных из JSON-файла и создания соответствующих объектов.

## Классы

### `Product`
Представляет товар с характеристиками.

**Атрибуты:**
- `name` (str) — название товара
- `description` (str) — описание
- `price` (float) — цена
- `category` (str, опционально) — категория товара
- `quantity` (int) — количество на складе (по умолчанию 0)

**Методы:**
- `__init__(self, name, description, price, category=None, quantity=0)` — конструктор.

---

### `Category`
Представляет категорию товаров. Хранит список продуктов, относящихся к категории.

**Атрибуты класса:**
- `category_count` (int) — общее количество созданных категорий.
- `product_count` (int) — общее количество товаров во всех категориях.

**Атрибуты экземпляра:**
- `name` (str) — название категории
- `description` (str) — описание категории
- `products` (list[Product]) — список товаров в категории

**Методы:**
- `__init__(self, name, description, products=None)` — конструктор. При создании категории увеличивает `category_count` и добавляет длину списка товаров в `product_count`.

---

## Утилиты (`utils.py`)

### `read_json(path: str) -> dict`
Читает JSON-файл по указанному пути и возвращает его содержимое в виде словаря.

**Параметры:**
- `path` — относительный или абсолютный путь к JSON-файлу.

**Возвращает:**
- `dict` — данные из файла.

---

### `created_object_for_json(data: list) -> list[Category]`
Принимает список словарей с данными о категориях и товарах, преобразует каждый товар в экземпляр `Product`, каждую категорию — в экземпляр `Category`, и возвращает список категорий.

**Параметры:**
- `data` — список категорий, полученный из JSON (см. формат ниже).

**Возвращает:**
- `list[Category]` — список объектов категорий с заполненными товарами.

---

## Формат JSON-файла

Файл должен содержать список категорий. Каждая категория описывается объектом:

```json
[
  {
    "name": "Название категории",
    "description": "Описание категории",
    "products": [
      {
        "name": "Товар 1",
        "description": "Описание товара",
        "price": 100.0,
        "quantity": 10
      },
      ...
    ]
  },
  ...
]
Поле category для товара не обязательно – оно не используется при создании объекта Product из JSON (конструктор принимает его опционально).

Пример использования
python
from src.utils import read_json, created_object_for_json

# Загружаем данные из файла
raw_data = read_json('../data/products.json')

# Создаём объекты категорий и товаров
categories = created_object_for_json(raw_data)

for cat in categories:
    print(f"Категория: {cat.name}, товаров: {len(cat.products)}")
    for prod in cat.products:
        print(f"  - {prod.name}, цена: {prod.price}, остаток: {prod.quantity}")
